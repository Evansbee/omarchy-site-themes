# Omarchy Site Themes

A small Chrome extension that recolors sites with your current Omarchy theme
and font, and follows you when you switch themes.

| Site | How |
|------|-----|
| Hacker News | Hand-written restyle (`sites/hackernews.css`) |
| Reddit, YouTube, Google News | Remaps the site's design tokens (`sites/*.css`) |
| GitHub | Primer tokens, generated by `tools/gen-github.js` |
| old Reddit, Penny Arcade, Edison Report, Inside Lighting, Daring Fireball, MMO-Champion, xkcd | `remap.js` engine |

## How it works

- `bin/omarchy-site-themes-sync` reads the current theme's `colors.toml` and
  writes the palette to `extension/colors.css` as `--om-*` CSS variables.
- A `theme-set` hook runs the sync script on every `omarchy theme set`.
- The extension's content script loads `colors.css` and re-reads it every
  couple of seconds while a tab is visible. A theme switch shows up in open
  tabs without a reload.
- `extension/sites/*.css` map the palette onto sites that expose design
  tokens (`--color-*`, `--yt-spec-*`, `--gm3-sys-color-*`, Primer).
- `extension/remap.js` handles sites that hard-code colors. It reads the
  site's stylesheets and inline styles, then re-expresses every color as a
  mix of palette variables using `palette.js`. Neutral colors keep their
  place between the site's background and text. Colorful ones snap to the
  nearest palette hue, and the site's dominant brand hue becomes the accent.
  Fills stay dark and text stays light (or the reverse for light themes),
  so text stays readable. Page wallpapers are dropped.

## Install

```bash
./install.sh
```

Then, in Chrome:

1. Open `chrome://extensions` and turn on **Developer mode**.
2. Click **Load unpacked** and pick this repo's `extension/` directory.

To turn the themes off, disable the extension.

## Reloading

Color and font changes need nothing. After editing the extension's code or
CSS, click the reload arrow on its card in `chrome://extensions`, then
refresh the site's tabs.

## Adding a site

1. Add a `content_scripts` entry to `extension/manifest.json`. Use
   `theme.js`, `palette.js`, `remap.js` for automatic remapping. For a
   hand-written theme, use `theme.js` plus `sites/<site>.css`, scoping
   every rule to `html[data-omarchy-themed]`.
2. Add the site's match pattern to `web_accessible_resources`.
3. If the site loads stylesheets from another host, add that host to
   `host_permissions`.
4. Reload the extension.
